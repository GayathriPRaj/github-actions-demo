# TypeScript User Creation Project

This project is a simple TypeScript web application with a landing page to create a user. User data is stored in a file within the project folder.

## Features
- Landing page: Create User
- User data is saved to a file on the server

## Getting Started

1. Install dependencies:
   ```
   npm install
   ```
2. Build the project:
   ```
   npm run build
   ```
3. Start the server:
   ```
   npm start
   ```

## Project Structure
- `src/` - TypeScript source files
- `public/` - Static assets and HTML
- `user-data.json` - File where user data is stored

## Notes
- This project uses Node.js with Express for the backend and basic HTML for the frontend.
- User data is stored in `user-data.json` in the project root.
